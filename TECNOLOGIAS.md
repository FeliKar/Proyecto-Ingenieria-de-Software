# Tecnologías y Dependencias

Documento con las tecnologías utilizadas y las dependencias
instaladas hasta el momento en MuniChat.

## Tecnologías

- **Frontend:** React 19 + TypeScript, Vite
- **Backend:** Node.js + Express 5 + TypeScript, TSX
- **Lenguaje:** TypeScript
- **Herramientas:** concurrently, oxlint, Git/GitHub
