# Team Charter — MuniChat

## Equipo

- Joaquín Fernández — Product Owner
- Pablo Tapia — Scrum Master
- Felipe Karmy — Developer
- Vicente Zapata — Desarrollo / Documentación

## Forma de trabajo

El equipo utilizará GitHub para administrar el código,
Issues para registrar historias y tareas, y GitHub Projects
para visualizar el estado del trabajo.

## Flujo

Backlog → Ready → In progress → In review → Done

## Reglas

- Cada integrante debe mantener actualizadas sus Issues.
- Las historias deben cumplir sus criterios de aceptación antes
  de pasar a Done.
- Los cambios de código deben ser revisados antes de considerarse
  terminados.
